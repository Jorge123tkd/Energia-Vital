# Instrucciones de continuidad — Bonaire
Este repositorio implementa la web Bonaire aunque su nombre técnico sea Energia-Vital.

Al comenzar o retomar una tarea, leer docs/CONTINUIDAD.md en la rama de trabajo y contrastar su estado con Git y los resultados disponibles.

Por instrucción explícita del usuario del 11 de noviembre de 2026:
- Después de cada paso completado o bloqueado, actualizar docs/CONTINUIDAD.md y guardar el cambio en GitHub.
- Registrar lo hecho, resultado, evidencia, último paso, pendientes y siguiente acción concreta.
- Distinguir código preparado, pruebas locales, cambios remotos y despliegue comprobado.
- No afirmar que algo se desplegó o verificó sin evidencia.
- No guardar credenciales, respaldos de bases de datos ni información privada en el registro.
- Mantener esta instrucción para futuros chats; usar GitHub como registro persistente.

Rama de trabajo: feat/cloudflare-customer-accounts-hardening. No sustituirla por main ni confundirla con la rama configurada para producción en Cloudflare Pages. Mantener cambios locales del usuario.
