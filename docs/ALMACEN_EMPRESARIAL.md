# Almacén empresarial — fase de esquema, no activado
La migración 025 añade un libro inmutable de movimientos en la autoridad comercial D1. No modifica artículos, precios ni existencias publicados. El inventario empieza sin artículos y sin saldos: se requiere inventario inicial verificado. Un artículo puede vincularse a un producto comercial o ser interno. Las cantidades se expresan como enteros en milésimas de la unidad fija. Reservar no descuenta físico; entregar a brigada sí, y disminuye la reserva; consumir solo reduce lo entregado; devolver repone físico; liberar elimina reserva. Operaciones limitadas por saldo por proyecto, sin duplicación de ID de movimiento; no se confirma una repetición como éxito sin futura comprobación idempotente del contenido.
El esquema autoriza únicamente administración activa; no hay endpoints ni acceso de brigadas todavía. La API futura debe verificar existencia y asignación del proyecto en Studio, vincular brigadas/órdenes y comprobar idempotencia (mismo ID y mismo contenido) antes de confirmar. Compras, ajuste de inventario auditado, devoluciones a proveedor, contabilidad monetaria, interfaz y reconciliación de stock publicado requieren entregas posteriores. No ejecutar migración en remoto hasta aprobar despliegue; pruebas únicamente datos ficticios.
